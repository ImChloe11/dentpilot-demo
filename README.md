# DentPilot 口腔临床智能工作台 Demo

DentPilot 是面向口腔综合科临床团队的智能工作台演示，涵盖预约与患者档案、接诊流程、可视化牙位图、语音辅助病历、质控、护理与病区管理，以及可旋转缩放的高精度 3D 口腔模型。

## 在线演示

部署完成后访问：

**https://imchloe11.github.io/dentpilot-demo/**

> 本项目当前使用虚拟患者数据，仅用于产品演示。所有智能分析均需医生审核确认；仅供医生参考，不构成诊断。

## 部署说明

仓库中的 `dentpilot-site-core.zip` 是已验证的静态页面包，两个 `.glb` 文件是成人恒牙 3D 模型。推送到 `main` 分支后，GitHub Actions 会自动组装并发布 GitHub Pages。

如需更新演示，请在本地重新构建并替换相应发布文件。
